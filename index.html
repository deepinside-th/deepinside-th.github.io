What If Studio: ส่งไฟล์เสียง ได้คลิปทั้งตอน

คลิปซ้ายมือทำด้วยสกิลนี้ทั้งหมด ภาพ การขยับ ซับ เพลง และเสียงเอฟเฟกต์ ไม่ได้ตัดต่อเองเลย

ทำเสียง TTS ให้

ElevenLabs บัญชีคุณ (ใช้เสียงโคลนตัวเองได้) หรือเสียงไทยฟรี โชว์บทกับเครดิตก่อน ยืนยันแล้วค่อยทำ แก้บรรทัดเดียวจ่ายบรรทัดเดียว

ตัวเลขอ่านถูก

"108 ล้าน" "1.5 ล้าน" "19:30" อ่านเหมือนคนพูด ไม่ต้องแก้บททีละคำ

การ์ตูนวาดด้วยโค้ด

ตัวละคร 8 ท่า ห้อง มือถือ ป้าย HUD ไม่ต้องเจนภาพ

เพลงตามอารมณ์

7 เพลง 6 อารมณ์ Claude อ่านบทแล้วเลือกให้

เสียงเอฟเฟกต์ 28 แบบ

ใส่ตรงจังหวะภาพอัตโนมัติ

ซับตรงเสียง

ตัดช่วงเงียบให้ ไม่เร่งเสียง และเช็กซับกับเสียงจริง

ฉากโหวต A/B

โบนัส: prompt 10 สไตล์

ตัวละครเดียว 10 ลุค ก๊อปวางในแชต Claude ได้เลย ดูตัวอย่าง

ต้องมีอะไรบ้าง (บอกตรงๆ)
  • คอม Windows 10/11 ว่างราว 2 GB (Mac ใช้ได้ แต่ยังเป็นรุ่นทดลอง)
  • Claude แพ็กเกจ Pro ขึ้นไป ราว 20 ดอลลาร์ (~฿700) ต่อเดือน จ่ายให้ Anthropic แยกจากค่าสกิล
  • เสียงพากย์: อัดเองเจ้าไหนก็ได้ หรือให้ Claude ทำผ่าน ElevenLabs (บัญชีและเครดิตของคุณ) หรือเสียงไทยฟรีของ Microsoft Edge (ไม่เป็นทางการ อาจใช้ไม่ได้บางวัน)
  • เน็ตสำหรับโหลดโมเดลถอดเสียงครั้งแรกราว 700 MB, ติดตั้ง 10-30 นาที

  • คนที่จะใช้แค่มือถือหรือ iPad
  • คนที่ไม่อยากจ่ายค่า Claude Pro
  • คนที่อยากได้คลิปพูดหน้ากล้อง หรือภาพเหมือนจริงแบบ AI video
  • คนที่อยากให้สกิลทำทั้งตอนในสไตล์อื่น (ตัวสกิลมีลุคเวกเตอร์ลุคเดียว ส่วน 10 สไตล์โบนัสเป็น prompt สำหรับแอนิเมชันสั้น)

Case file 03 · Pro

พิมพ์แค่ "อยากทำคลิปแนวมนุษย์เงินเดือน"

นี่คือผลจริงจากการรันครั้งแรกเมื่อ 15 พ.ย. 2569 ไม่ได้แต่งเพิ่ม Claude ทำครบทุกขั้นแล้วเก็บเป็นไฟล์ให้ทั้งหมด

หาเรื่องที่คนพูดถึง

Google Trends ไทย + ข่าว ได้ 8 เรื่อง พร้อมลิงก์และวันที่ เช่น เลิกจ้างเดือนละสี่หมื่นคน, AI เริ่มทำงานแทนคนออฟฟิศ, ขึ้นเงินเดือนแค่ 2-3%

ห้าไอเดียพร้อมคะแนน

ให้คะแนน hook, ทำไมต้องตอนนี้, A/B สูสีไหม, วาดง่ายไหม, ปลอดภัยไหม แล้วแนะนำหนึ่งเรื่อง

แผน 7 ตอน

กฎของเรื่อง ตัวละคร hook ใหม่ทุกตอน และตอนจบ 3 แบบตามผลโหวต

บทที่ผ่านการตรวจ

ร่างแรกยาว 88 วิ ระบบตรวจเจอ ตัดเหลือ 73 วิ มีจุดหักมุมสม่ำเสมอ ไม่พูดเรื่องโหวตก่อนท้ายคลิป

แผนฉาก

20 ช็อต บอกเวลา สิ่งที่ขยับ ของที่ต้องวาด และเสียงเอฟเฟกต์

แผนโพสต์

ปฏิทินลงคลิป แคปชันก๊อปวาง 4 แพลตฟอร์ม สิ่งที่ต้องทำชั่วโมงแรก และวันรุ่งขึ้นต้องดูยอดตรงไหน

ไอเดียที่ระบบแนะนำ (23/25 คะแนน)
  • Hook: ทุกวันศุกร์ หัวหน้าคุณไล่คนออกหนึ่งคน แต่หัวหน้าคนนี้ไม่ใช่คน
  • ทำไมตอนนี้: ข่าวเลย์ออฟ + AI แทนงานออฟฟิศ + บริษัททดลองให้ AI เป็นหัวหน้า
  • โหวต: พิมพ์ชื่อคนอื่นให้โดนแทน / ลบ AI ทิ้ง (ผิดกฎหมาย กล้องเห็น)
บอกตรงๆ
  • ไม่มีใครการันตียอดวิวได้ ระบบช่วยเลือกเรื่องและวางโครง แล้วคุณปรับตามยอดจริง
  • บางครั้งข่าวเดือนนี้ยังค้นไม่เจอ ระบบจะบอกว่าข่าวใหม่สุดที่หาได้เป็นของเดือนไหน ไม่แต่งเอง
  • เรื่องในคลิปเป็นเรื่องแต่ง ไม่เล่าคดีจริงของคนจริง ไม่ลอกช่องอื่น
  • Claude ไม่โพสต์แทนคุณ และไม่ขอรหัสผ่านใดๆ

คำถามที่เจอบ่อย

ต้องมี Claude หรือ AI ตัวไหนไหม

Playbook ไม่ต้อง ใช้กับ CapCut หรือโปรแกรมไหนก็ได้ ส่วน Studio ต้องมี Claude Code แพ็กเกจ Pro ขึ้นไป

Studio กับ Pro ต่างกันยังไง

Studio: คุณมีบทอยู่แล้ว Claude ทำเสียงและทำคลิปให้ Pro: คุณบอกแค่แนวคลิป Claude หาเรื่อง เสนอไอเดีย เขียนบท วางแผนทั้งสัปดาห์และแผนโพสต์ให้ด้วย พร้อมสกิลเจนภาพ gemini-image และ Playbook ซื้อ Studio ไปก่อนแล้วอัปเกรดทีหลังได้ จ่ายเพิ่ม ฿400

ทำเสียง TTS ต้องจ่ายเพิ่มไหม

เสียงไทยฟรีของ Microsoft Edge ไม่ต้องจ่าย (แต่ไม่เป็นทางการ อาจใช้ไม่ได้บางวัน) ถ้าใช้ ElevenLabs ใช้บัญชีและเครดิตของคุณเอง ก่อนทำทุกครั้ง Claude จะโชว์บทที่จะอ่านกับเครดิตที่ใช้ แล้วรอคุณพิมพ์รหัสยืนยันก่อน key ของคุณเก็บในเครื่องคุณ ไม่ได้ส่งมาที่เรา

ราคานี้ถึงเมื่อไหร่

ราคาเปิดตัวถึง 31 ธ.ค. 2569 หลังจากนั้นเป็น ฿199 / ฿790 / ฿1,490 คนที่ซื้อแล้วได้อัปเดตรุ่นถัดไปฟรี

Studio ติดตั้งยากไหม

แตกไฟล์ zip แล้วดับเบิลคลิก install.bat รอราว 10-30 นาที (โหลดโมเดลถอดเสียงไทยราว 700 MB) ติดตรงไหนทักไลน์ได้ ช่วยดูให้

คลิปที่ทำด้วย Studio เป็นของใคร

เป็นของคุณ ลงช่องตัวเอง สร้างรายได้ หรือรับงานลูกค้าได้ไม่จำกัด แต่ห้ามแจกหรือขายตัวสกิลต่อ

ได้ไฟล์ทางไหน

ลิงก์ Google Drive ที่เปิดได้เฉพาะอีเมลของคุณ ส่งเข้าไลน์และอีเมล ดาวน์โหลดเก็บไว้ได้ตลอด

ใช้บนมือถือได้ไหม

ไม่ได้ Studio ต้องรันบนคอม Windows หรือ Mac เพราะต้องใช้ Claude Code วาดและเรนเดอร์คลิปในเครื่อง ส่วน Playbook อ่านบนมือถือได้

นอกจากค่าสกิล ต้องจ่ายอะไรอีกไหม

ค่า Claude แพ็กเกจ Pro ราว ฿700 ต่อเดือน (จ่ายให้ Anthropic เอง สมัครเดือนเดียวก็ลองได้) กับค่าเสียงพากย์ถ้าใช้ ElevenLabs (มีเสียงฟรีให้เลือก) ตัวสกิลไม่มีค่าเจนภาพ เพราะวาดด้วยโค้ดทั้งหมด ส่วน gemini-image ใน Pro ใช้โควตาฟรีของบัญชี Google คุณ

คืนเงินได้ไหม

เป็นสินค้าดิจิทัล จึงไม่คืนเงินหลังส่งไฟล์ ยกเว้นไฟล์เปิดไม่ได้หรือโอนซ้ำ ทักมาได้ทันที
